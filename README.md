# Anonymous Telegram Moderation Bot

Telegram-бот для анонимных сообщений с модерацией в админ-конфе:
- пользователь отправляет сообщение боту в личку;
- бот копирует сообщение в админ-конфу с кнопками `Сгенерировать теги`, `Отклонить`, `Ответить`, `Забанить`;
- после генерации тегов администратор получает предпросмотр с кнопками `Опубликовать` и `Редактировать теги`;
- администратор публикует в канал, отклоняет по шаблонной причине, отвечает пользователю, банит или разбанивает пользователя;
- личности пользователя и модераторов не раскрываются, так как используется копирование сообщений, а не пересылка.

## Возможности

- Поддержка текста, ссылок, фото, видео, голосовых и других типов сообщений.
- Корректная обработка медиагрупп (альбомов) и массовых вложений.
- Whitelist модераторов через `ADMIN_USER_IDS`.
- Причины отклонения вынесены в отдельный файл `data/reject_reasons.json`.
- Генерация top-3 тегов через Chad AI (`gpt-5-nano`) с ручным редактированием перед публикацией.
- Бан/разбан пользователей через кнопки в админ-конфе.

## Структура

- `main.py` — запуск бота и регистрация роутеров.
- `config.py` — загрузка настроек из переменных окружения.
- `handlers/user_messages.py` — прием сообщений от пользователей и создание кейсов.
- `handlers/admin_actions.py` — модерация: tag generation/reject/reply/ban/unban/publish.
- `handlers/ui.py` — inline-клавиатуры.
- `services/case_store.py` — in-memory реестр кейсов.
- `services/media_bridge.py` — безопасное копирование сообщений/альбомов.
- `services/tagging_service.py` — вызов Chad API и выбор релевантных тегов.
- `services/ban_store.py` — хранение банов пользователей.
- `services/reject_reasons.py` — чтение причин отклонения.
- `data/reject_reasons.json` — список причин отклонения.
- `data/bans.json` — сохраненные баны.

## Переменные окружения

Скопируйте `.env.example` в `.env` и заполните:

- `BOT_TOKEN` — токен Telegram-бота.
- `ADMIN_CHAT_ID` — id админ-конфы (где проходят модерацию).
- `PUBLISH_CHANNEL_ID` — id канала для публикаций.
- `ADMIN_USER_IDS` — список id модераторов через запятую.
- `POST_SIGNATURE` — legacy-поле (можно не использовать).
- `CHAD_API_KEY` — API-ключ Chad.
- `CHAD_BASE_URL` — базовый URL API (по умолчанию `https://ask.chadgpt.ru/api/v1`).
- `CHAD_MODEL` — модель для тегирования (по умолчанию `gpt-5-nano`).

## Локальный запуск

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python main.py
```

## Деплой на Bothost

1. Запушьте проект в GitHub/GitLab.
2. В панели Bothost создайте нового Telegram-бота и укажите URL репозитория и ветку.
3. Добавьте env-переменные из раздела выше в настройках бота.
4. Запустите деплой и проверьте логи.

## Важно

- Хранилище кейсов сделано in-memory. После перезапуска бота незакрытые кейсы теряются.
- Баны хранятся в `data/bans.json` и сохраняются между рестартами.
- Если Chad API недоступен или возвращает ошибку, бот использует fallback-тег `#тейк`; затем можно нажать `Редактировать теги` и задать теги вручную.
